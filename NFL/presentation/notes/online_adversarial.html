Online Adversarial No-Free-Lunch

Week — No-Free-Lunch Theorems

DSC 190/291 Learning Theory  ·  Tianhao Wang  ·  UCSD Spring 2026

1. Setting

We study a learner that receives labelled examples one at a time and must predict the label of a new point before seeing its true label. An adversary simultaneously chooses a target function to maximise the learner's mistakes.

Definition 1 (Domain and queries). Let $\mathcal{X}$ be any set (the domain). A query sequence is a finite list $x_1, x_2, \ldots, x_T \in \mathcal{X}$. We say the sequence is non-repeating if all $x_t$ are distinct.
Definition 2 (Deterministic online learner). A deterministic online learner is a function $$A : \underbrace{\bigl(\mathcal{X} \times \{0,1\}\bigr)^*}_{\text{history}} \;\times\; \mathcal{X} \;\longrightarrow\; \{0,1\}.$$ At round $t$, having observed the labelled history $h_t = \bigl((x_1, f(x_1)), \ldots, (x_{t-1}, f(x_{t-1}))\bigr)$, the learner predicts $A(h_t,\, x_t)$.

Define the history up to round $t$ against target $f$ on query sequence $\mathbf{x} = (x_1,\ldots,x_T)$ as $$\mathrm{hist}(f, \mathbf{x}, t) \;=\; \bigl((x_1, f(x_1)),\, \ldots,\, (x_{t-1}, f(x_{t-1}))\bigr).$$

Definition 3 (Mistake at round $t$). Learner $A$ makes a mistake at round $t$ against target $f$ on query sequence $\mathbf{x}$ if $$A\!\bigl(\mathrm{hist}(f,\mathbf{x},t),\; x_t\bigr) \;\neq\; f(x_t).$$ We write this as $\mathrm{MistakeAt}(A, f, \mathbf{x}, t)$.

2. Main Theorem

Theorem 1 (Online Adversarial No-Free-Lunch). For any deterministic online learner $A$ and any non-repeating query sequence $\mathbf{x} = (x_1, \ldots, x_T)$, there exists a target function $f : \mathcal{X} \to \{0,1\}$ such that $A$ makes a mistake at every round: $$\forall\, t \in \{1, \ldots, T\},\quad \mathrm{MistakeAt}(A,\, f,\, \mathbf{x},\, t).$$
Takeaway. No deterministic online learner can avoid all mistakes against an adversarial target — even on a sequence of distinct queries.

3. Proof

The proof is by induction on the query sequence $\mathbf{x}$. The key idea is to construct the adversarial target incrementally: define the label at $x_1$ to fool $A$, then treat the remaining rounds as a fresh problem for a shifted learner.

Induction structure

Proof. We prove: for every learner $A$ and every non-repeating sequence $\mathbf{x}$, there exists $f$ that fools $A$ at every round. The proof is by induction on $|\mathbf{x}|$.

Base case: empty sequence

Base case. If $\mathbf{x} = ()$, there are no rounds. The constant function $f \equiv 0$ satisfies the claim vacuously.
□

Inductive step: $\mathbf{x} = (x_1, x_2, \ldots, x_T)$

Assume the claim holds for every learner and every non-repeating sequence of length $T - 1$. We handle a non-repeating sequence of length $T$. Since $\mathbf{x}$ is non-repeating, $x_1 \notin \{x_2, \ldots, x_T\}$.

Step 1. Adversarial label for round 1. Define $$b \;:=\; \lnot\, A\!\bigl([], x_1\bigr).$$ By construction, $A([], x_1) \neq b$, so any target with $f(x_1) = b$ fools $A$ at round 1.

Step 2. Shifted learner. Define the shifted learner $$A'(h, y) \;:=\; A\!\bigl((x_1, b) \mathbin{::} h,\; y\bigr).$$ Intuitively, $A'$ is $A$ pretending that round 1 already happened with label $b$.

Step 3. Apply the inductive hypothesis. The tail $(x_2, \ldots, x_T)$ is non-repeating (it inherits this from $\mathbf{x}$). By the induction hypothesis applied to $A'$ and $(x_2, \ldots, x_T)$, there exists $g : \mathcal{X} \to \{0,1\}$ such that $$\forall\, t \in \{1, \ldots, T-1\},\quad A'\!\bigl(\mathrm{hist}(g,\,(x_2,\ldots,x_T),\,t),\; x_{t+1}\bigr) \;\neq\; g(x_{t+1}).$$

Step 4. Combined target. Define $$f(y) \;:=\; \begin{cases} b & \text{if } y = x_1, \\ g(y) & \text{otherwise.} \end{cases}$$

Lemma 1 (History agreement). For every $t \geq 1$, $$\mathrm{hist}(f,\,\mathbf{x},\,t+1) \;=\; (x_1, b) \mathbin{::} \mathrm{hist}(g,\,(x_2,\ldots,x_T),\,t).$$
Proof of Lemma 1. The history $\mathrm{hist}(f, \mathbf{x}, t+1)$ consists of the pairs $(x_i, f(x_i))$ for $i = 1, \ldots, t$. The first pair is $(x_1, f(x_1)) = (x_1, b)$. For $i \geq 2$, since $x_1 \notin \{x_2,\ldots,x_T\}$, we have $x_i \neq x_1$, so $f(x_i) = g(x_i)$. Thus the tail of the history is $\mathrm{hist}(g, (x_2,\ldots,x_T), t)$.
□

Verification

Round 1. The history is empty, the query is $x_1$, and $f(x_1) = b$. By construction of $b$, $$A\!\bigl([], x_1\bigr) \;\neq\; b \;=\; f(x_1). \checkmark$$

Round $t+1$ (for $t \geq 1$). The query is $x_{t+1}$. By Lemma 1, the history is $(x_1,b) :: \mathrm{hist}(g,(x_2,\ldots,x_T),t)$. Therefore $$A\!\bigl(\mathrm{hist}(f,\mathbf{x},t+1),\; x_{t+1}\bigr) \;=\; A\!\bigl((x_1,b) :: \mathrm{hist}(g,(x_2,\ldots,x_T),t),\; x_{t+1}\bigr) \;=\; A'(\mathrm{hist}(g,(x_2,\ldots,x_T),t),\; x_{t+1}).$$ Since $x_{t+1} \neq x_1$ (as $\mathbf{x}$ is non-repeating), we have $f(x_{t+1}) = g(x_{t+1})$. By the inductive hypothesis on $g$, $$A'\!\bigl(\mathrm{hist}(g,(x_2,\ldots,x_T),t),\; x_{t+1}\bigr) \;\neq\; g(x_{t+1}) = f(x_{t+1}). \checkmark$$

Conclusion. The target $f$ fools $A$ at every round $t \in \{1,\ldots,T\}$.
□

4. Proof Summary

Adversarial target construction (informal algorithm)
  1. Given learner $A$ and non-repeating sequence $(x_1,\ldots,x_T)$.
  2. Set $b := \lnot A([], x_1)$.
  3. Define shifted learner: $A'(h, y) := A((x_1, b) :: h,\; y)$.
  4. Recursively find $g$ that fools $A'$ on $(x_2,\ldots,x_T)$.
  5. Output $f(y) := b$ if $y = x_1$, else $g(y)$.
Remark. The target $f$ is constructed without knowing the full sequence in advance: the adversary only needs to know $A$'s prediction on the current query and the history it has seen. The recursion produces $f$ one coordinate at a time.
Remark (Why non-repeating?). The non-repeating condition is used in two places: (i) to ensure $x_1 \notin \{x_2,\ldots,x_T\}$, which is needed for the history agreement (Lemma 1); (ii) to pass a valid non-repeating sequence to the inductive hypothesis. Without it, $A$ could query the same point twice — but a consistent adversary would simply reuse the already-assigned label.

5. Formal Statement in Lean 4

The following is the machine-verified statement and proof sketch. The full Lean 4 proof lives in NFL/claude_full/OnlineAdversarial.lean. 

-- Deterministic online learner
abbrev OnlineLearner (X : Type*) := List (X × Bool) → X → Bool

-- History seen before round t
def historyTo (f : X → Bool) (xs : List X) (t : Nat) : List (X × Bool) :=
  (xs.take t).map fun x => (x, f x)

-- Mistake predicate
def MistakeAt (A : OnlineLearner X) (f : X → Bool) (xs : List X) (t : Nat) :=
  ∀ h : t < xs.length,
    A (historyTo f xs t) (xs.get ⟨t, h⟩) ≠ f (xs.get ⟨t, h⟩)

-- Main theorem
theorem exists_adversarial_target
    (A : OnlineLearner X) (xs : List X) (hxs : xs.Nodup) :
    ∃ f : X → Bool, ∀ t, MistakeAt A f xs t := by
  induction xs generalizing A with
  | nil  => -- vacuously true
      exact ⟨fun _ => false, fun t h => absurd h (by simp)⟩
  | cons x xs ih =>
      let b  := !A [] x                              -- adversarial label
      let A' := fun h y => A ((x, b) :: h) y         -- shifted learner
      obtain ⟨g, hg⟩ := ih A' (nodup_tail hxs)       -- inductive hypothesis
      let f  := fun y => if y = x then b else g y   -- combined target
      exact ⟨f, ⟨round-0 and round-(t+1) cases⟩⟩

6. Further Discussion

Connection to the PAC and batch settings

Theorem 1 is an adversarial result: the adversary picks the target after seeing the learner. In the PAC setting the target is fixed before learning begins, which is why sample-efficient learning is possible for restricted hypothesis classes (finite VC dimension). Theorem 1 shows that if we allow the adversary to adapt, no learner can survive even on a finite query sequence.

Computational interpretation

The adversarial construction is explicit and efficient: at each step $t$ the adversary computes $b = \lnot A(h_t, x_t)$ in time proportional to one evaluation of $A$, then sets $f(x_t) = b$. No exponential search is required.

Key insight. The proof is a reduction: fooling a learner on $T$ rounds reduces to fooling a shifted learner on $T-1$ rounds. The shift operation $(x_1, b) :: h$ "commits" the adversary's first move while leaving all future choices free.
