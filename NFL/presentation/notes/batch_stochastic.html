Batch Stochastic No-Free-Lunch

Week — No-Free-Lunch Theorems

DSC 190/291 Learning Theory  ·  Tianhao Wang  ·  UCSD Spring 2026

1. Setting

Definition 1 (Learner, risk, failure probability).

A deterministic learner is a function $A : (\mathcal{X} \times \{0,1\})^* \to (\mathcal{X} \to \{0,1\})$.

The population risk of hypothesis $h$ under distribution $D$ is $$L_D(h) \;:=\; \mathbb{P}_{(x,y)\sim D}[h(x) \neq y].$$

The empirical risk on sample $S = ((x_1,y_1),\ldots,(x_n,y_n))$ is $$L_n(h) \;:=\; \frac{1}{n}\sum_{i=1}^n \mathbf{1}[h(x_i) \neq y_i].$$

A distribution $D$ on $\mathcal{X}\times\{0,1\}$ is realizable (by $\mathcal{H}$) if $\inf_{h\in\mathcal{H}} L_D(h) = 0$.

2. Main Theorem

Theorem 1 (Batch Stochastic No-Free-Lunch). Let $\mathcal{X}$ be any domain. For every learning algorithm $A$ and every $n < |\mathcal{X}|/2$, there exists a realizable distribution $D$ on $\mathcal{X}\times\{0,1\}$ such that $$\mathbb{P}_{S\sim D^n}\!\bigl[L_D(A(S)) \geq \tfrac{1}{8}\bigr] \;\geq\; \frac{1}{7}.$$
Remark (Quantifier order). The theorem quantifies over every algorithm $A$ and every sample size $n$ first. After these are fixed, the adversary picks: a set of $2n$ distinct domain points, a bad target labeling on those points, and the realizable distribution supported on those labeled points. This is an oblivious adversary — the distribution is fixed before the sample is drawn.
Takeaway. Without structural restrictions on the hypothesis class, no learner can achieve low risk with high probability on every realizable distribution. For every fixed $A$ and $n$, there is a hard realizable distribution.

Comparison with the Online Adversarial setting

The Online Adversarial theorem uses an adaptive adversary: at each round, the adversary sees the learner's prediction and sets the opposite label. Here, the adversary is oblivious: distribution $D$ and target $f^*$ are fixed before any sample is drawn. Both say the same thing qualitatively — without structural restrictions, no learner wins — but via different mechanisms: adaptive fooling in the online case vs. an information-theoretic blindspot in the batch case.

3. Proof

The proof has four steps: construct an averaging family of distributions, show the average loss is $\geq 1/4$, extract a single bad labeling by the probabilistic method, and convert expected loss to constant-probability failure.

Step 1: The Averaging Construction

Fix algorithm $A$ and $n < |\mathcal{X}|/2$. Choose $2n$ distinct points $x_1, \ldots, x_{2n} \in \mathcal{X}$. For each labeling vector $b = (b_1,\ldots,b_{2n}) \in \{0,1\}^{2n}$, define:

  • Target function: $f_b : \mathcal{X} \to \{0,1\}$ with $f_b(x_i) = b_i$ for $i = 1,\ldots,2n$ (arbitrary elsewhere).
  • Distribution: $D_b\bigl((x_i, b_i)\bigr) = \dfrac{1}{2n}$ for $i = 1,\ldots, 2n$ — uniform on the $2n$ labeled graph points.

By construction $L_{D_b}(f_b) = 0$, so every $D_b$ is realizable.

Step 2: Average Population Loss $\geq \tfrac{1}{4}$

Let $B = (B_1,\ldots,B_{2n})$ be drawn uniformly at random from $\{0,1\}^{2n}$. Sampling $S \sim D_B^n$ is equivalent to:

  1. Draw $B$ uniformly from $\{0,1\}^{2n}$.
  2. Draw indices $J_1,\ldots,J_n$ i.i.d. uniformly from $[2n]$, independently of $B$.
  3. Output $S = \bigl((x_{J_1}, B_{J_1}),\ldots,(x_{J_n}, B_{J_n})\bigr)$.
Lemma 1 (Unseen points contribute independent errors). Define the observed set $V(S) = \{i \in [2n] : x_i \text{ appears in } S\}$ and the unseen set $U(S) = [2n] \setminus V(S)$. Then: $$\mathbb{E}_B\,\mathbb{E}_{S \sim D_B^n}\!\bigl[L_{D_B}(A(S))\bigr] \;\geq\; \frac{1}{4}.$$
Proof. Since the sample has only $n$ examples, $|V(S)| \leq n$, so $|U(S)| \geq n$.

Condition on the realized sample $S$. The hypothesis $\hat{h} = A(S)$ is then fixed. For any $i \in U(S)$, the bit $B_i$ was never revealed in $S$, so conditional on $S$ it is still an unbiased fair coin, independent of $\hat{h}(x_i)$. Therefore: $$\mathbb{E}\!\bigl[\mathbf{1}[\hat{h}(x_i) \neq B_i] \;\big|\; S\bigr] = \frac{1}{2} \quad \text{for every } i \in U(S).$$

Hence:

$$\mathbb{E}[L_{D_B}(A(S)) \mid S] = \frac{1}{2n}\sum_{i=1}^{2n}\mathbb{E}[\mathbf{1}[\hat{h}(x_i) \neq B_i] \mid S] \;\geq\; \frac{|U(S)|}{2n} \cdot \frac{1}{2} \;\geq\; \frac{n}{2n} \cdot \frac{1}{2} = \frac{1}{4}.$$

Taking expectation over $S$ and $B$:

$$\mathbb{E}_B\,\mathbb{E}_{S\sim D_B^n}\!\bigl[L_{D_B}(A(S))\bigr] \;\geq\; \frac{1}{4}.$$
□

Step 3: Extracting a Single Bad Labeling

Probabilistic method. Since the average over all $b \in \{0,1\}^{2n}$ is at least $\tfrac{1}{4}$, there exists at least one labeling $b^*$ such that $$\mathbb{E}_{S \sim D_{b^*}^n}\!\bigl[L_{D_{b^*}}(A(S))\bigr] \;\geq\; \frac{1}{4}.$$ Set $D = D_{b^*}$. This distribution is realizable (by $f_{b^*}$ with $L_D(f_{b^*}) = 0$).
□

Step 4: From Expected Loss to Constant-Probability Failure

Markov-style argument. Let $Z = L_D(A(S)) \in [0,1]$. We have $\mathbb{E}[Z] \geq \tfrac{1}{4}$. Set $p = \mathbb{P}(Z \geq \tfrac{1}{8})$. Since $0 \leq Z \leq 1$: $$\mathbb{E}[Z] \;\leq\; (1-p)\cdot\frac{1}{8} + p \cdot 1 = \frac{1}{8} + \frac{7p}{8}.$$ Combining with $\mathbb{E}[Z] \geq \tfrac{1}{4}$: $$\frac{1}{4} \leq \frac{1}{8} + \frac{7p}{8} \;\implies\; p \geq \frac{1}{7}.$$ Therefore $$\mathbb{P}_{S \sim D^n}\!\bigl[L_D(A(S)) \geq \tfrac{1}{8}\bigr] \;\geq\; \frac{1}{7}.\quad\square$$
□

4. Proof Summary

Proof structure at a glance
  1. Averaging construction. Fix $A$, $n$, and $2n$ domain points. For each labeling $b \in \{0,1\}^{2n}$, define $D_b$ = uniform on the graph of $f_b$ (realizable by construction).
  2. Lower bound $\geq \tfrac{1}{4}$. For any sample $S$ of size $n$, at least $n$ points are unseen. Each unseen $B_i$ is an independent fair coin given $S$, contributing error $\tfrac{1}{2}$. So $\mathbb{E}[L_{D_B}(A(S))] \geq n/(2n) \cdot \tfrac{1}{2} = \tfrac{1}{4}$.
  3. Probabilistic method. Average over $b \geq \tfrac{1}{4}$ implies some $b^*$ has $\mathbb{E}_{S\sim D_{b^*}^n}[L_{D_{b^*}}(A(S))] \geq \tfrac{1}{4}$.
  4. Markov conversion. $\mathbb{E}[Z] \geq \tfrac{1}{4}$ and $Z \in [0,1]$ imply $\mathbb{P}(Z \geq \tfrac{1}{8}) \geq \tfrac{1}{7}$.
Remark (Why the constants $\tfrac{1}{8}$ and $\tfrac{1}{7}$?). The key equation is $\mathbb{E}[Z] \leq \tfrac{1}{8} + \tfrac{7}{8}\,p$. With $\mathbb{E}[Z] \geq \tfrac{1}{4}$, the tightest lower bound on $p$ is $p \geq \tfrac{1/4 - 1/8}{7/8} = \tfrac{1}{7}$. The threshold $\tfrac{1}{8}$ is chosen so that $\tfrac{1}{8} < \tfrac{1}{4}$, leaving room for the Markov argument to give $p > 0$. Any threshold $\varepsilon < \tfrac{1}{4}$ works; the resulting failure probability is $\tfrac{1/4-\varepsilon}{1-\varepsilon}$.
Remark (The core information-theoretic insight). A sample of size $n$ from a $2n$-point domain inevitably misses at least $n$ points. The labels at those unseen points are unpredictable — even by the best possible learner — because the labeling $B_i$ is an independent coin given the sample. This information-theoretic blindspot is the fundamental obstacle.

5. Formal Verification in Lean 4

The Lean 4 proof in NFL/claude_full/BatchStochastic.lean uses the same four-step structure. The main differences from the pen-and-paper proof are the use of measure theory (Measure.pi for the product measure $D^n$) and an abstract subtype $Z \hookrightarrow \mathcal{X}$ to represent the $2n$-point support. 

-- A deterministic learning algorithm
abbrev Learner (X : Type*) := List (X × Bool) → (X → Bool)

-- Population risk  L_D(h) = ∫ 1[h(x) ≠ y] dD
noncomputable def risk (D : Measure (X × Bool)) (h : X → Bool) : ℝ :=
  ∫ xy, (if h xy.1 = xy.2 then 0 else 1) ∂D

-- D_b = uniform on graph of f_b over {x_1,...,x_{2n}}
noncomputable def graphPMF (C : Finset X) (f : X → Bool) (hC : C.Nonempty)
    : PMF (X × Bool) :=
  PMF.uniformOfFinset (graphFinset C f) (graphFinset_nonempty f hC)

-- Step 2: for any sample S, average over labelings gives risk ≥ |unseen|/(2|C|) ≥ 1/4
theorem sum_abstractRisk_ge (S : Fin m → Z) ... :
    (Fintype.card (Fin m → Z) : ℝ) / 4 ≤
      ∑ f : Z → Bool, abstractRisk e f (A (abstractSampleList e f S))

-- Step 3: some labeling has failure rate ≥ 1/7  (probabilistic method)
theorem exists_abstractFailureRate_ge (C : Finset X) ... :
    ∃ fZ : Z → Bool, (1 : ℝ) / 7 ≤ abstractFailureRate e A fZ m

-- Main theorem
theorem batch_stochastic_NFL
    [Fintype X] [MeasurableSingletonClass X] [Nonempty X]
    (A : Learner X) (m : Nat) (hm : 2 * m ≤ Fintype.card X) :
    ∃ D : Measure (X × Bool), IsProbabilityMeasure D ∧
      (∃ f : X → Bool, risk D f = 0) ∧
      (1 : ℝ) / 7 ≤ failureProb D A m (1 / 8)
