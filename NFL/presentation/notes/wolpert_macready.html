Wolpert–Macready No-Free-Lunch

Week — No-Free-Lunch Theorems

DSC 190/291 Learning Theory  ·  Tianhao Wang  ·  UCSD Spring 2026  ·  Based on Wolpert & Macready (1997)

1. The Framework — Four Objects

The paper studies black-box optimisation: an algorithm repeatedly queries a cost function $f : \mathcal{X} \to \mathcal{Y}$ at distinct points and observes the values, trying to minimise or characterise $f$ without access to its analytic form. Everything is encoded in four objects.

1 — Sample

$d_m = \{(x_1, y_1), \ldots, (x_m, y_m)\}$ — time-ordered set of $m$ distinct points queried so far with their observed cost values. Write $d_m^x = (x_1, \ldots, x_m)$ for the query sequence and $d_m^y = (y_1, \ldots, y_m)$ for the cost-value sequence.

2 — Algorithm

$a : d \mapsto x \notin d^x$ — a deterministic map from the current sample to the next query, required to be a previously unvisited point. Covers hill climbing, simulated annealing, genetic algorithms, tabu search — any method that doesn't use $f$'s analytic structure.

3 — Performance

Fully encoded by $P(d_m^y \mid f, m, a)$ — the probability that algorithm $a$ produces exactly cost-value sequence $d_m^y$ on function $f$ after $m$ queries. Any scalar measure $\Phi(d_m^y)$ (best-so-far, mean cost, etc.) is a function of this distribution.

4 — Prior

$P(f)$ over $\mathcal{F} = \mathcal{Y}^{\mathcal{X}}$. The space $\mathcal{F}$ has $|\mathcal{Y}|^{|\mathcal{X}|}$ elements — finite but enormous. The uniform prior $P(f) = 1/|\mathcal{F}|$ represents complete ignorance about which problem we face.

Remark (Why probability if the algorithm is deterministic?). Three reasons: (i) the framework extends cleanly to stochastic algorithms, (ii) probability language provides a clean proof framework via sums over $\mathcal{F}$, (iii) the prior $P(f)$ encodes our ignorance of which cost function we face, even when $f$ is technically fixed.

2. Main Theorem — Static NFL

Theorem 1 (Wolpert–Macready, 1997 — Static NFL). For any two (possibly stochastic) black-box search algorithms $a_1$ and $a_2$, any number of queries $m$, and any target cost-value sequence $d_m^y$: $$\sum_{f \in \mathcal{F}} P(d_m^y \mid f,\, m,\, a_1) \;=\; \sum_{f \in \mathcal{F}} P(d_m^y \mid f,\, m,\, a_2).$$

What it actually says. Fix any target cost-value sequence $d_m^y$ you would like to obtain. The number of cost functions $f \in \mathcal{F}$ on which algorithm $a$ produces exactly that sequence is the same for every $a$. Averaged over all cost functions, hill climbing, simulated annealing, evolutionary algorithms, and uniform random search are indistinguishable.

Corollary (Equal expected performance). For any scalar performance measure $\Phi : (\mathcal{Y}^m) \to \mathbb{R}$: $$\sum_{f \in \mathcal{F}} \mathbb{E}_a[\Phi(d_m^y)] \;\text{ is the same for every } a.$$ No algorithm achieves better average performance than any other when averaging over all $f \in \mathcal{F}$.
Takeaway. Any algorithm's gain on one class of problems is exactly offset by losses elsewhere. The "skill" of a real-world optimiser is not intrinsic — it is an alignment between the algorithm's inductive bias and the (non-uniform) prior $P(f)$ over problems actually encountered.

3. Proof of Theorem 1

The proof is by induction on $m$ (the number of queries). The key structural insight is to split the sum over $f \in \mathcal{F}$ into a product of independent sums over coordinates inside and outside the already-queried set $d_m^x$.

Base case ($m = 1$)

Base case. With no sample yet, algorithm $a$ makes its first query $x_1 = a(\emptyset)$. This is a deterministic choice (given $a$). The event "$d_1^y = (y_1)$" requires $f(x_1) = y_1$ — fixing exactly one coordinate of $f$. The remaining $|\mathcal{X}| - 1$ coordinates are unconstrained, so exactly $|\mathcal{Y}|^{|\mathcal{X}|-1}$ functions in $\mathcal{F}$ satisfy $f(x_1) = y_1$. This count does not depend on which $x_1$ the algorithm chose, so $$\sum_{f \in \mathcal{F}} P(d_1^y \mid f, 1, a) = |\mathcal{Y}|^{|\mathcal{X}|-1} \quad \text{for every } a.$$
□

Inductive step

Assume the identity holds for $m$ queries. We prove it for $m+1$.

Inductive step. Decompose: $$P(d_{m+1}^y \mid f, m+1, a) = P\!\bigl(d_{m+1}^y(m+1) \mid d_m^y, f, m+1, a\bigr) \cdot P(d_m^y \mid f, m, a).$$ The next query $x_{m+1} = a(d_m^x, d_m^y)$ depends only on the values of $f$ at points inside $d_m^x$, which are already determined by $d_m^y$. The new observation $y_{m+1} = f(x_{m+1})$ depends only on $f$'s value at a point outside $d_m^x$ (since $a$ never revisits).

Split the sum over $\mathcal{F}$ into independent sums over the "inside" coordinates (those in $d_m^x$) and the "outside" coordinates (everything else):

$$\sum_{f \in \mathcal{F}} P(d_{m+1}^y \mid f, m+1, a) = \underbrace{\sum_{f^{\mathrm{out}}}}_{|\mathcal{X}|-m-1 \text{ free coords}} \!\!\Bigl[\mathbf{1}[f^{\mathrm{out}}(x_{m+1}) = y_{m+1}]\Bigr] \cdot \underbrace{\sum_{f^{\mathrm{in}}} P(d_m^y \mid f^{\mathrm{in}}, m, a)}_{=\;|\mathcal{Y}|^{|\mathcal{X}|-m}\text{ (IH)}}$$ The "outside" sum counts functions agreeing at $x_{m+1}$: it equals $|\mathcal{Y}|^{|\mathcal{X}|-m-1}$ regardless of $a$. The "inside" sum is the inductive hypothesis — also independent of $a$. Their product $|\mathcal{Y}|^{|\mathcal{X}|-m-1} \cdot |\mathcal{Y}|^{|\mathcal{X}|-m}$ is independent of $a$.
□
Core insight. Any deterministic algorithm merely picks coordinates of $f$ in some order. Summing over all $f \in \mathcal{F}$ makes every ordering — and therefore every algorithm — equivalent.

4. The Geometric Picture

The theorem has an elegant geometric reformulation (Wolpert & Macready, §IV). Think of $\mathcal{F}$ as an index set with $|\mathcal{F}|$ elements and define:

  • $\vec{v}_{d_m^y,\, a,\, m}(f) := P(d_m^y \mid f, m, a)$ — the behaviour vector of algorithm $a$ in $|\mathcal{F}|$-dimensional space.
  • $\vec{p}(f) := P(f)$ — the prior vector over cost functions.

The expected performance of $a$ on sequence $d_m^y$ under prior $P$ is the dot product: $$P(d_m^y \mid m, a) \;=\; \vec{v}_{d_m^y,\, a,\, m} \cdot \vec{p}.$$

Different algorithms correspond to different vectors $\vec{v}_{a,m}$ off the diagonal (their projections onto $\vec{1}$ are equal — that is Theorem 1). Algorithm $a$ performs well on prior $\vec{p}$ iff $\vec{v}_a$ points in a similar direction to $\vec{p}$, i.e., iff the algorithm's bias is aligned with the true prior.

Remark (What good performance means geometrically). "Algorithm $a$ is good for problem class $P$" is not an intrinsic property of $a$. It is the geometric statement $\vec{v}_a \cdot \vec{p} > \vec{v}_{a'} \cdot \vec{p}$, which requires knowing $\vec{p}$. An algorithm can only outperform another by exploiting a specific non-uniform prior over problems.

5. Extensions and Scope

Stochastic algorithms

Replace deterministic $a$ with a hyperparameter $\sigma$ specifying $P(x_{m+1} \mid d_m, \sigma)$. The proof carries through identically: the "outside/inside" split still works because the stochastic choice of $x_{m+1}$ still depends only on $d_m^y$ (the inside), not on any outside coordinate.

Time-varying cost functions (Theorem 2)

If the cost function evolves by a bijection $T : \mathcal{F} \times \mathbb{N} \to \mathcal{F}$ (so $f_{i+1} = T_i(f_i)$), then averaging over all bijections $T$ (rather than all $f$) for a fixed initial $f_1$ again yields algorithm-independence. The proof replaces the single sum over $f$ with a chain of sums over $T_1, T_2, \ldots$; each inner sum counts bijections mapping a fixed function to a target — a constant $(|\mathcal{F}|-1)!$ — independent of $a$.

When NFL holds beyond uniform $P(f)$

This is critical for defending against the objection "but real problems aren't uniformly distributed." NFL also holds for any prior $P(f)$ that is:

  • Factorisable: $P(f) = \prod_{x \in \mathcal{X}} P'(f(x))$ — cost values at different domain points are i.i.d. under the prior.
  • Closed under permutations of rank-ordered cost values — the prior does not prefer any particular ordering of outputs.

Uniform $P(f)$ is typical among priors yielding NFL, not pathological. The mere existence of structure in $P(f)$ is not enough to justify any particular algorithm — the structure must be known and exploited.

6. Proof Summary

Proof structure at a glance
  1. Base case ($m=1$): First query fixes one coordinate of $f$; $|\mathcal{Y}|^{|\mathcal{X}|-1}$ consistent functions — independent of which $x_1$ the algorithm chose.
  2. Inductive step ($m \to m+1$): Decompose $P(d_{m+1}^y \mid f, m+1, a)$ into (next-observation) $\times$ (history probability). Split sum over $f$ into "outside" coordinates (determines $y_{m+1}$, gives $|\mathcal{Y}|^{|\mathcal{X}|-m-1}$, independent of $a$) and "inside" coordinates (the induction hypothesis, independent of $a$).
  3. Conclude: Product is $|\mathcal{Y}|^{|\mathcal{X}|-m-1} \cdot |\mathcal{Y}|^{|\mathcal{X}|-m}$, independent of $a_1$ vs. $a_2$.

7. Formal Verification in Lean 4

The Lean 4 proof uses a continuation-based formulation that mirrors the inductive structure above. The "inside/outside" split becomes the distinction between the consistent-target count (inside, via consistentEquivComplement) and the non-revisiting condition (outside, via NonRevisiting). 

-- A possibly-stochastic search algorithm
structure SearchAlg (X Y : Type*) where
  nextQuery : List (X × Y) → PMF X   -- P(x_{m+1} | d_m, a)

-- Non-revisiting encodes "a : d ↦ x ∉ d^x"
def SearchAlg.NonRevisiting (A : SearchAlg X Y) : Prop :=
  ∀ (h : List (X × Y)) (x : X),
    x ∈ h.map Prod.fst → A.nextQuery h x = 0

-- P(d_m^y | f, m, a): PMF over cost-value sequences
noncomputable def observations (A : SearchAlg X Y) (f : X → Y) (m : Nat)
    : PMF (List Y) := (trace A f m).map (·.map Prod.snd)

-- Σ_f P(d_m^y | f, m, a): the sum in Theorem 1
noncomputable def avgFuture [Fintype (X → Y)]
    (A : SearchAlg X Y) (h : List (X × Y)) (c : List Y) : ℝ≥0∞ :=
  ∑ f : X → Y, if Consistent f h
    then observationsFrom A f h c.length c else 0

-- Key lemma: Σ_f P(d_m^y | f, m, a) = |Y|^(|X| - m), independent of a
theorem avgFuture_eq_pow
    [Fintype X] [Fintype Y] [DecidableEq X]
    (A : SearchAlg X Y) (hA : A.NonRevisiting)
    (h : List (X × Y)) (hh : (h.map Prod.fst).Nodup)
    (c : List Y) (hbound : h.length + c.length ≤ Fintype.card X) :
    avgFuture A h c =
      (Fintype.card Y ^ (Fintype.card X - (h.length + c.length)) : ℝ≥0∞) := by
  induction c generalizing h with
  | nil   => -- base: count consistent targets (= "inside" sum)
      simp [avgFuture, ← consistentCount_eq_pow_card hh]
  | cons y ys ih =>
      rw [avgFuture_cons]  -- expand over next query
      -- NonRevisiting kills seen x (= "outside" contributes constant)
      -- IH closes fresh x; PMF sums to 1 finishes
      calc ∑' x, A.nextQuery h x * avgFuture A (h.concat (x, y)) ys
          = ∑' x, A.nextQuery h x * K := tsum_congr (...)
        _ = K := by rw [ENNReal.tsum_mul_right, PMF.tsum_coe]; simp

-- Theorem 1 statement
theorem wolpert_macready ... :
    (∑ f : X → Y, observations A₁ f m c) =
      ∑ f : X → Y, observations A₂ f m c :=
  -- avgFuture_eq_pow from empty history gives |Y|^(|X|-m) for both
  by rw [hsum₁, hsum₂, avgFuture_eq_pow A₁ h₁ .., avgFuture_eq_pow A₂ h₂ ..]

8. Discussion and Common Objections

"But surely SA beats random search on real problems?"

Yes — because real problems are not uniformly distributed. SA's bias toward local search aligns with the local-correlation structure of typical engineering problems. NFL says this alignment must be paid for by SA's poor performance on problems where local structure is misleading (deceptive functions, needle-in-haystack). The advantage is real; the theorem says it cannot be free.

"Doesn't NFL contradict the existence of universal learners?"

No. PAC-style universal learners assume restricted hypothesis classes or smoothness conditions — they encode a non-uniform prior. NFL is consistent with all such results; it just says universality without such restrictions is impossible.

Head-to-head asymmetries are still possible

NFL does not preclude one algorithm beating another on a particular $f$. The averages match because gains on some $f$ are exactly offset by losses on others. Theorem 9 of Wolpert & Macready rules out head-to-head asymmetries only when the two algorithms' sampled point sets never overlap.

Key insight. NFL is almost a counting argument: every $f$ appears once in the sum, every algorithm visits coordinates in some order, end of story. The depth is conceptual — it forces the field to abandon vague claims of algorithmic superiority and articulate what prior is being assumed.
Remark (Connection to supervised learning NFL). This result is the optimisation analogue of Wolpert's earlier NFL for supervised learning (1996). Both say: averaged over all possible targets, all learners/optimisers are equivalent. VC dimension, regularisation, and structural risk minimisation are all ways of encoding inductive bias — NFL tells you why that encoding is mandatory, not optional.
