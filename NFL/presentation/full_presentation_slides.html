Online Adversarial — Setting

Online Prediction Protocol

At each round $t = 1, \ldots, T$:

  1. Instance $x_t \in \mathcal{X}$ arrives.
  2. Learner sees history $H_{t-1} = \bigl((x_1,y_1),\ldots,(x_{t-1},y_{t-1})\bigr)$, predicts $\hat{y}_t = A(H_{t-1})(x_t)$.
  3. True label $y_t$ revealed; mistake if $\hat y_t \neq y_t$.
Learner. $A : (\mathcal{X}\times\{0,1\})^* \to (\mathcal{X}\to\{0,1\})$
Mistake count. $M_T = \displaystyle\sum_{t=1}^T \mathbf{1}[\hat y_t \neq y_t]$
Adaptive adversary. Sees $\hat y_t$ before committing to $y_t$. One bit of information per round suffices to fool any $A$.
Distinct instances. $x_1,\ldots,x_T$ all distinct — ensures $f$ is well-defined and prevents information gain from revisits.
5
Online Adversarial — Theorem & Proof
Theorem 1 (Online Adversarial NFL). For any deterministic $A$ and $T$ distinct instances $x_1,\ldots,x_T$, $\;\exists\, f : \mathcal{X}\to\{0,1\}$ such that $M_T = T$.
Proof. Construct $f$ round by round. At round $t$, the learner computes $\hat y_t = A(H_{t-1})(x_t)$. Define: $$f(x_t) \;:=\; 1 - \hat y_t \;=\; 1 - A(H_{t-1})(x_t)$$ Then $y_t = f(x_t) = 1 - \hat y_t \neq \hat y_t$ — every round is a mistake.
  • Well-defined: $x_1,\ldots,x_T$ distinct → each point labeled exactly once.
  • Causally consistent: $H_{t-1}$ uses only $y_i = f(x_i)$ defined at rounds $i < t$.
  • Adversary only needs the single bit $\hat y_t$ — no knowledge of $A$'s internals. $\;\square$
Key insight. The adaptive adversary exploits one bit of information per round. No deterministic learner — however sophisticated — can avoid this.

Framework — Four Objects (Probabilistic)

Four Objects

Sample
$D_m = (\vec{x}^{(m)}, \vec{y}^{(m)})$
$m$ distinct query–value pairs, time-ordered. $x_i \neq x_j$ for $i \neq j$ (no revisits).
Algorithm
$\mathcal{A} : D_m \mapsto P(\,\cdot\,\mid D_m, \mathcal{A})$
Conditional distribution over $\mathcal{X}\setminus\{\vec{x}^{(m)}\}$. Deterministic case = delta distribution.
Performance
$P(\vec{y}^{(m)} \mid f, m, \mathcal{A}) \in [0,1]$
Probability that $\mathcal{A}$ produces $\vec{y}^{(m)}$ on $f$ in $m$ queries. Now genuinely in $[0,1]$ — not just $\{0,1\}$.
Prior
$P(f)$ uniform on $\mathcal{F} = \mathcal{Y}^{\mathcal{X}}$
$|\mathcal{F}| = |\mathcal{Y}|^{|\mathcal{X}|}$. Uniform prior = complete ignorance over which $f$ we face.
Black-box. $\mathcal{A}$ takes only $D_m$ as input — it does not see $f$ directly. Its randomness is internal to $\mathcal{A}$; $\mathcal{A}$ itself (the specification of all its conditional distributions) is fixed.

Theorem & Corollary
Theorem (Wolpert–Macready, 1997 — Probabilistic NFL). For any two non-revisiting (possibly stochastic) algorithms $\mathcal{A}_1, \mathcal{A}_2$, any $m$, and any target cost-value sequence $\vec{y}^{(m)}$: $$\sum_{f \in \mathcal{F}} P\!\bigl(\vec{y}^{(m)} \mid f, m, \mathcal{A}_1\bigr) \;=\; \sum_{f \in \mathcal{F}} P\!\bigl(\vec{y}^{(m)} \mid f, m, \mathcal{A}_2\bigr) \;=\; |\mathcal{Y}|^{|\mathcal{X}|-m}.$$
Corollary. For any performance measure $\Phi : \mathcal{Y}^m \to \mathbb{R}$: $$\sum_{f \in \mathcal{F}} \mathbb{E}_{\mathcal{A}}\bigl[\Phi(\vec{y}^{(m)})\bigr] \;\text{ is the same for every } \mathcal{A}.$$

Proof of corollary. Expand the expectation, swap the order of summation (finite sums), and pull $\Phi(\vec{y}^{(m)})$ out of the inner sum (it does not depend on $f$):

$$\sum_{f} \mathbb{E}_{\mathcal{A}}[\Phi] = \sum_{\vec{y}^{(m)} \in \mathcal{Y}^m} \Phi(\vec{y}^{(m)}) \cdot \underbrace{\sum_{f \in \mathcal{F}} P(\vec{y}^{(m)} \mid f, m, \mathcal{A})}_{=\,|\mathcal{Y}|^{|\mathcal{X}|-m}\text{ by Theorem}}.$$

Each inner sum is algorithm-independent; the outer weighted sum inherits the property. $\;\square$

Reading. Any quantity that is a function only of the observed cost-value sequence has algorithm-invariant average over $\mathcal{F}$. Best-so-far, mean cost, variance, indicator of reaching optimum — all covered.

Proof — Strategy: Trace + Coordinate Split

The Stochastic Decomposition

A trace is a query sequence $\vec{x}^{(m)}$ the algorithm might generate. For any candidate $\vec{x}^{(m)}$, define the trace probability $$\pi(\vec{x}^{(m)}) \;:=\; \prod_{i=1}^m P\bigl(x_i \,\big|\, D_{i-1},\, \mathcal{A}\bigr), \qquad D_{i-1} = (\vec{x}^{(i-1)}, \vec{y}^{(i-1)}).$$ Here $\vec{y}^{(i-1)}$ uses the target values; $\pi(\vec{x}^{(m)})$ depends on $\mathcal{A}$ and the target $\vec{y}^{(m)}$, not on $f$.

Marginalise over traces. Summing over consistent traces: $$P(\vec{y}^{(m)} \mid f, m, \mathcal{A}) \;=\; \sum_{\vec{x}^{(m)}} \pi(\vec{x}^{(m)}) \cdot \mathbf{1}\bigl[f(\vec{x}^{(m)}) = \vec{y}^{(m)}\bigr].$$

The indicator depends only on $f|_{S_{\text{in}}(\vec{x}^{(m)})}$ where $S_{\text{in}}(\vec{x}^{(m)}) = \{\vec{x}^{(m)}\}$.

Inside/outside split. For each fixed trace $\vec{x}^{(m)}$, partition $\mathcal{X}$:
  • $S_{\text{in}} = \{\vec{x}^{(m)}\}$: $m$ coordinates pinned by the indicator.
  • $S_{\text{out}} = \mathcal{X} \setminus S_{\text{in}}$: $|\mathcal{X}|-m$ free coordinates.

Specifying $f$ = independently specifying $(f|_{S_{\text{in}}}, f|_{S_{\text{out}}})$, so $\sum_{f \in \mathcal{F}} = \sum_{f|_{S_{\text{in}}}} \sum_{f|_{S_{\text{out}}}}$.

Stochasticity adds one outer layer (sum over traces, weighted by $\pi$). The inside/outside count happens trace-by-trace; the trace weights collapse via $\sum_{\vec{x}^{(m)}} \pi(\vec{x}^{(m)}) = 1$.

Proof — Base Case ($m = 1$)

Stochasticity in Action

With no sample yet, $\mathcal{A}$ draws $x_1$ from $P(\,\cdot\,\mid \emptyset, \mathcal{A})$ — a distribution over $\mathcal{X}$. Then $$P(\vec{y}^{(1)} \mid f, 1, \mathcal{A}) \;=\; \sum_{x_1 \in \mathcal{X}} P(x_1 \mid \emptyset, \mathcal{A}) \cdot \mathbf{1}[f(x_1) = y_1].$$ This is in $[0,1]$, not just $\{0,1\}$.

Compute the sum. Swap the order of summation (finite sums, Fubini is automatic): $$\sum_{f \in \mathcal{F}} P(\vec{y}^{(1)} \mid f, 1, \mathcal{A}) \;=\; \sum_{x_1} P(x_1 \mid \emptyset, \mathcal{A}) \;\cdot\; \underbrace{\sum_{f \in \mathcal{F}} \mathbf{1}[f(x_1) = y_1]}_{(\star)}.$$

$(\star)$ counts functions with $f(x_1)$ fixed: $|\mathcal{Y}|^{|\mathcal{X}|-1}$ — same for every $x_1$.

Pull out the constant. $$\sum_{f} P(\vec{y}^{(1)} \mid f, 1, \mathcal{A}) \;=\; |\mathcal{Y}|^{|\mathcal{X}|-1} \cdot \underbrace{\sum_{x_1 \in \mathcal{X}} P(x_1 \mid \emptyset, \mathcal{A})}_{=\,1\text{ (probabilities sum to 1)}} \;=\; |\mathcal{Y}|^{|\mathcal{X}|-1}. \quad \square$$
Why this works. The count $(\star) = |\mathcal{Y}|^{|\mathcal{X}|-1}$ is independent of which $x_1$ the algorithm might choose. So the weighted average over $x_1$ equals that constant value, regardless of how $\mathcal{A}$ distributes its first query. Randomisation buys nothing — a microcosm of the full theorem.

Proof — Inductive Step ($m \to m+1$)

IH: $\;\sum_{f} P(\vec{y}^{(m)} \mid f, m, \mathcal{A}) = |\mathcal{Y}|^{|\mathcal{X}|-m}$ for every $\mathcal{A}$ and every $\vec{y}^{(m)}$. Equivalently (via the trace decomposition): $\sum_{\vec{x}^{(m)}} \pi(\vec{x}^{(m)}) = 1$.

Chain rule (stochastic). Split the $(m+1)$-step trace into the first $m$ queries and the $(m+1)$-th: $$P(\vec{y}^{(m+1)} \mid f, m+1, \mathcal{A}) = \sum_{\vec{x}^{(m)}} \pi(\vec{x}^{(m)}) \,\mathbf{1}[f(\vec{x}^{(m)}) = \vec{y}^{(m)}] \cdot \sum_{x_{m+1} \in S_{\text{out}}} \!\!P(x_{m+1} \mid D_m, \mathcal{A}) \,\mathbf{1}[f(x_{m+1}) = y_{m+1}].$$

The no-revisit rule forces $x_{m+1} \in S_{\text{out}}$. The first factor depends on $f|_{S_{\text{in}}}$; the second on $f|_{\{x_{m+1}\}} \subset f|_{S_{\text{out}}}$ — disjoint coordinates.

Sum over $f$, factorise. For each fixed pair $(\vec{x}^{(m)}, x_{m+1})$ (all $m+1$ points distinct): $$\sum_{f} \mathbf{1}[f(\vec{x}^{(m)}) = \vec{y}^{(m)}] \,\mathbf{1}[f(x_{m+1}) = y_{m+1}] \;=\; |\mathcal{Y}|^{|\mathcal{X}|-(m+1)} \quad \text{(pins $m+1$ coords, leaves the rest free).}$$

This count is independent of which $\vec{x}^{(m)}, x_{m+1}$ — only the number of pinned coordinates matters.

Collapse the trace sums. $$\sum_{f} P(\vec{y}^{(m+1)} \mid f, m+1, \mathcal{A}) = |\mathcal{Y}|^{|\mathcal{X}|-(m+1)} \cdot \sum_{\vec{x}^{(m)}} \pi(\vec{x}^{(m)}) \underbrace{\sum_{x_{m+1}} P(x_{m+1} \mid D_m, \mathcal{A})}_{=\,1} = |\mathcal{Y}|^{|\mathcal{X}|-(m+1)}. \quad \square$$

Inner sum collapses (next-query distribution sums to 1); outer sum collapses by IH ($\sum_{\vec{x}^{(m)}} \pi = 1$).

Core insight. Whether $\mathcal{A}$ is deterministic or stochastic, the count $|\mathcal{Y}|^{|\mathcal{X}|-m}$ depends only on $|\mathcal{X}|, |\mathcal{Y}|, m$ — not on which order the algorithm visits coordinates, nor on how it randomises. All algorithms are equivalent averaged over $f$.

Batch Stochastic — Definition & Theorem
Definition 1 (Learner, risk, failure probability).

A deterministic learner: $A:(\mathcal{X}\times\{0,1\})^*\to(\mathcal{X}\to\{0,1\})$.

Population risk: $L_D(h):=\mathbb{P}_{(x,y)\sim D}[h(x)\neq y]$.   $D$ is realizable if $\inf_{h\in\mathcal{H}} L_D(h)=0$.

Theorem 3 (Batch Stochastic NFL). For every deterministic $A$ and $n < |\mathcal{X}|/2$, $\;\exists$ realizable $D$ on $\mathcal{X}\times\{0,1\}$ such that $$\mathbb{P}_{S\sim D^n}\!\bigl[L_D(A(S)) \geq \tfrac{1}{8}\bigr] \;\geq\; \frac{1}{7}$$
Key quantifier order. Learner $A$ is chosen first $\;\Longrightarrow\;$ bad distribution $D$ is chosen after. The adversary tailors $D$ to $A$'s specific strategy.
Adaptive vs Oblivious adversary.

Adaptive (online): adversary sees $A$'s prediction each round before setting the label — fully responsive, maximally powerful.

Oblivious (here): adversary commits to $D$ once, before the first data point is drawn — blind to all training and predictions.

Batch Stochastic — Proof Intuition
Setup. Adversary picks $2n$ domain points $x_1,\ldots,x_{2n}$. Training sample $S$ has only $n$ examples — even with no repeats, learner sees at most $n$ distinct points.
Key observation. Among $2n$ points, at least $n$ are unseen — invisible to $A$. That is at least half the distribution support.
Error calculation. On each unseen point $A$ has no information — prediction is no better than guessing: $$\text{error on unseen point} = \frac{1}{2}$$ $$\text{unseen mass} \;\geq\; \frac{n}{2n} = \frac{1}{2}$$ $$\mathbb{E}\bigl[L_D(A(S))\bigr] \;\geq\; \frac{1}{2}\cdot\frac{1}{2} \;=\; \frac{1}{4}$$

Batch Proof — Step 1: Build Many Possible Hard Distributions
Setup. Fix an arbitrary learner $A$ and sample size $n$. Choose $2n$ distinct domain points $x_1,\ldots,x_{2n}\in\mathcal{X}$.
Family of distributions. For every binary labeling $b=(b_1,\ldots,b_{2n})\in\{0,1\}^{2n}$, define a target function and distribution: $$f_b(x_i) = b_i, \qquad D_b\bigl((x_i,\,b_i)\bigr) = \frac{1}{2n}.$$ $D_b$ is the uniform distribution over the $2n$ labeled points $\{(x_i,b_i)\}_{i=1}^{2n}$.
Realizability. The target $f_b$ achieves zero population risk under $D_b$: $$L_{D_b}(f_b) \;=\; \mathbb{P}_{(x,y)\sim D_b}[f_b(x)\neq y] \;=\; 0.$$ So every $D_b$ is a valid realizable distribution. There are $2^{2n}$ such distributions — one per labeling.
17
Batch Proof — Steps 2&3: Randomize Labeling; Unseen Labels Stay Random
Step 2 — Proof device. Let $B=(B_1,\ldots,B_{2n})$ with $B_i\overset{\text{i.i.d.}}{\sim}\text{Bern}(\tfrac12)$. Draw $S\sim D_B^n$. This is only an averaging trick — the final result uses a fixed labeling $b^*$.
Seen / Unseen sets. $$V(S) = \{i\in[2n]:x_i\text{ appears in }S\},\quad |V(S)|\leq n,$$ $$U(S) = [2n]\setminus V(S),\qquad\qquad\;\; |U(S)|\geq n.$$ At least half the $2n$ support points are invisible to the learner.
Step 3 — Key line. Condition on $S$: the hypothesis $\hat h = A(S)$ is now fixed. For any $i\in U(S)$, bit $B_i$ was never revealed in $S$ — it remains an independent fair coin: $$\mathbb{E}\bigl[\mathbf{1}[\hat h(x_i)\neq B_i]\,\bigm|\,S\bigr] = \frac{1}{2}.$$ The learner may output anything at $x_i$, but the true unseen label is an independent coin — error probability is exactly $\tfrac{1}{2}$.
18
Batch Proof — Step 4: Lower-Bound the Expected Population Risk
Population risk under $D_B$. $$L_{D_B}(A(S)) \;=\; \frac{1}{2n}\sum_{i=1}^{2n}\mathbf{1}\bigl[A(S)(x_i)\neq B_i\bigr]$$
Conditional bound (given $S$). Since $\mathbb{E}[\mathbf{1}[\cdots]\mid S]=\tfrac12$ for each $i\in U(S)$ and $|U(S)|\geq n$: $$\mathbb{E}\bigl[L_{D_B}(A(S))\bigm| S\bigr] \;\geq\; \frac{|U(S)|}{2n}\cdot\frac{1}{2} \;\geq\; \frac{n}{2n}\cdot\frac{1}{2} \;=\; \frac{1}{4}.$$
Unconditional bound (tower law). Taking expectation over $S$ and $B$: $$\mathbb{E}_B\,\mathbb{E}_{S\sim D_B^n}\!\bigl[L_{D_B}(A(S))\bigr] \;\geq\; \frac{1}{4}.$$ Averaged over all $2^{2n}$ possible labelings, every learner $A$ suffers expected risk $\geq\tfrac{1}{4}$.
19
Batch Proof — Step 5: Extract One Fixed Bad Labeling
Where we are. Steps 2–4 established: $$\mathbb{E}_B\,\mathbb{E}_{S\sim D_B^n}\!\bigl[L_{D_B}(A(S))\bigr] \;\geq\; \frac{1}{4}.$$ The left side is an average over all $2^{2n}$ labelings $b\in\{0,1\}^{2n}$.
Probabilistic method. If the average of a quantity over a finite set is $\geq c$, at least one element must itself be $\geq c$. Therefore $\exists\,b^*\in\{0,1\}^{2n}$ such that: $$\mathbb{E}_{S\sim D_{b^*}^n}\!\bigl[L_{D_{b^*}}(A(S))\bigr] \;\geq\; \frac{1}{4}.$$
Set $D = D_{b^*}$. This is the fixed bad distribution promised by Theorem 3. It is realizable (by $f_{b^*}$, which has zero risk), and learner $A$ suffers expected population risk $\geq\tfrac{1}{4}$ under $D$.
20
Batch Proof — Step 6: Convert Expected Loss to Failure Probability
Setup. Let $Z = L_D(A(S))\in[0,1]$ with $S\sim D^n$. We know $\mathbb{E}[Z]\geq\tfrac{1}{4}$. Let $p = \mathbb{P}(Z\geq\tfrac{1}{8})$. Goal: show $p\geq\tfrac{1}{7}$.
Upper-bound $\mathbb{E}[Z]$ by splitting on $\tfrac{1}{8}$.

If $Z < \tfrac{1}{8}$: that piece contributes $\leq\tfrac{1}{8}(1-p)$.

If $Z \geq \tfrac{1}{8}$: that piece contributes $\leq 1\cdot p$ (since $Z\leq 1$).

$$\mathbb{E}[Z] \;\leq\; (1-p)\cdot\frac{1}{8}+p\cdot 1 \;=\; \frac{1}{8}+\frac{7p}{8}$$
Combine and solve. $$\frac{1}{4} \;\leq\; \frac{1}{8}+\frac{7p}{8} \;\Longrightarrow\; \frac{1}{8}\leq\frac{7p}{8} \;\Longrightarrow\; p\;\geq\;\frac{1}{7}.\quad\square$$ $$\mathbb{P}_{S\sim D^n}\!\bigl[L_D(A(S))\geq\tfrac{1}{8}\bigr]\;\geq\;\frac{1}{7}.$$
Why $\tfrac{1}{8}$ and $\tfrac{1}{7}$. $\tfrac{1}{8}$ is a convenient threshold below $\tfrac{1}{4}$. The general Markov bound gives: $$p\;\geq\;\frac{\mathbb{E}[Z]-\varepsilon}{1-\varepsilon}\;=\;\frac{1/4-1/8}{7/8}\;=\;\frac{1}{7}.$$ Any $\varepsilon<\tfrac{1}{4}$ works — the constants are not magical.

Lean — Wolpert–Macready: Formal Statements

Histogram identity

theorem wolpert_macready
    [Fintype X] [Fintype Y] [DecidableEq X]
    (A₁ A₂ : SearchAlg X Y) (m : Nat)
    (hm : m ≤ Fintype.card X)
    (h₁ : A₁.NonRevisiting)
    (h₂ : A₂.NonRevisiting)
    (c : List Y) (hc : c.length = m) :
    (∑ f : X → Y, observations A₁ f m c) =
       ∑ f : X → Y, observations A₂ f m c

Expected performance corollary

theorem wolpert_macready_avg
    [Fintype X] [Fintype Y] [DecidableEq X]
    (A₁ A₂ : SearchAlg X Y) (m : Nat)
    (hm : m ≤ Fintype.card X)
    (h₁ : A₁.NonRevisiting)
    (h₂ : A₂.NonRevisiting)
    (φ : List Y → ℝ≥0∞) :
    (∑ f : X → Y,
        expectedPerformance A₁ f m φ) =
       ∑ f : X → Y,
        expectedPerformance A₂ f m φ
Note. observations A f m c — the count of $f$s producing exactly sequence $c$. expectedPerformance — summed against any score $\phi$.

Lean — Batch Stochastic: Formal Statement

Top-level theorem

theorem batch_stochastic_NFL
    [Fintype X] [Nonempty X]
    [MeasurableSingletonClass X]
    (A : Learner X) (m : Nat)
    (hm : 2 * m ≤ Fintype.card X) :
    ∃ D : Measure (X × Bool),
      IsProbabilityMeasure D ∧
      (∃ f : X → Bool, risk D f = 0) ∧
      (1 : ℝ) / 7 ≤
        failureProb D A m (1 / 8)
Learner X. abbrev Learner X := List (X × Bool) → (X → Bool)
failureProb D A m ε. $\mathbb{P}_{S\sim D^{\otimes m}}[L_D(A(S))\geq\varepsilon]$ under product measure Measure.pi.
[Nonempty X] is essential. no_probability_measure_empty_prod_bool proves there is no probability measure on Empty × Bool — so the theorem would be vacuously false without this assumption.
risk D f. Bochner integral of 0-1 loss. risk_graphPMF_self_zero proves realizability.
