1. Setting
2
Setting: Online Learning

Learning proceeds in rounds. At each round:

  1. Adversary selects a query $x_t \in \mathcal{X}$
  2. Learner predicts $\hat{y}_t \in \{0,1\}$ before seeing the true label
  3. Adversary reveals label $y_t = f(x_t)$; learner suffers if $\hat{y}_t \neq y_t$
Definition. A deterministic online learner is a map $$A : \bigl(\mathcal{X} \times \{0,1\}\bigr)^* \times \mathcal{X} \;\longrightarrow\; \{0,1\}$$ that produces a prediction given the labelled history and the current query.
Definition. A query sequence $\mathbf{x} = (x_1, \ldots, x_T)$ is non-repeating if all queries are distinct.

Write $h_t = \bigl((x_1, f(x_1)), \ldots, (x_{t-1}, f(x_{t-1}))\bigr)$ for the history at round $t$.

3
Mistakes and the Adversarial Goal
Definition (Mistake at round $t$). Learner $A$ makes a mistake at round $t$ against target $f$ on sequence $\mathbf{x}$ if $$A(h_t,\, x_t) \;\neq\; f(x_t).$$

Goal of the adversary: choose $f$ so that $A$ makes a mistake at every round.

Goal of the learner: choose a strategy $A$ so that no target $f$ causes mistakes at every round.

Question. Can a deterministic learner guarantee that no adversary fools it on every round of a non-repeating sequence?

Answer: No. This is the Online Adversarial No-Free-Lunch Theorem.

4
2. Main Theorem
5
Online Adversarial No-Free-Lunch
Theorem (Online Adversarial NFL). For any deterministic online learner $A$ and any non-repeating query sequence $\mathbf{x} = (x_1, \ldots, x_T)$, there exists a target $f : \mathcal{X} \to \{0,1\}$ such that $$\forall\, t \in \{1,\ldots, T\},\quad A(h_t,\, x_t) \;\neq\; f(x_t).$$

In words: for every learner and every non-repeating query schedule, some target makes the learner wrong at every single round.

  • The result is worst-case: the target $f$ may depend on $A$ and $\mathbf{x}$.
  • The construction is explicit: no probabilistic argument needed.
  • Proof method: induction on the query sequence.
There is no free lunch: every online learner can be fooled completely by an adaptive adversary.

3. Proof
7
Proof Overview

We prove by induction on $|\mathbf{x}|$:

For every learner $A$ and non-repeating $\mathbf{x}$, $\exists f$ that fools $A$ everywhere.

Base case

$\mathbf{x} = ()$. No rounds exist. Any $f$ works vacuously.

Inductive step

Given $\mathbf{x} = (x_1, x_2, \ldots, x_T)$ with $x_1 \notin \{x_2,\ldots,x_T\}$, we build $f$ in 4 steps:

  1. Adversarial label $b$ for round 1
  2. Shifted learner $A'$ for the tail
  3. Inductive hypothesis on $A'$, $(x_2,\ldots,x_T)$
  4. Combined target $f$
Key idea. Fool the learner on round 1 immediately, then pretend round 1 already happened to reduce to a fresh $(T{-}1)$-round problem.
8
Construction — Steps 1 & 2

Step 1. Adversarial label for round 1.

Set $\;b \;:=\; \lnot\, A([\,], x_1).$

Since $A$'s prediction on empty history is $A([], x_1)$, the opposite $b$ fools $A$ at round 1 for any target with $f(x_1) = b$.

Step 2. Shifted learner.

Define $A' : (\mathcal{X}\times\{0,1\})^* \times \mathcal{X} \to \{0,1\}$ by $$A'(h,\, y) \;:=\; A\!\bigl(\,(x_1, b) :: h,\; y\,\bigr).$$

$A'$ simulates $A$ as if round 1 already happened with history entry $(x_1, b)$. It is again a valid deterministic online learner.

Intuition. Prepending $(x_1, b)$ to every future history is the "shift": it moves $A$ one step forward in time, so that the tail problem starts fresh.
9
Construction — Steps 3 & 4

Step 3. Apply the inductive hypothesis.

The tail $(x_2, \ldots, x_T)$ is non-repeating (inherited from $\mathbf{x}$). By IH applied to $A'$ and $(x_2,\ldots,x_T)$: $$\exists\; g : \mathcal{X}\to\{0,1\} \quad \text{s.t.} \quad \forall t\in\{1,\ldots,T{-}1\},\quad A'\!\bigl(h'_t,\, x_{t+1}\bigr) \;\neq\; g(x_{t+1}),$$ where $h'_t = \mathrm{hist}(g, (x_2,\ldots,x_T), t)$.

Step 4. Combined target.

$$f(y) \;=\; \begin{cases} b & y = x_1 \\ g(y) & y \neq x_1 \end{cases}$$

Since $x_1 \notin \{x_2,\ldots,x_T\}$, the two cases never conflict.

$f$ is well-defined. It remains to verify: $A$ makes a mistake at every round.
10
Verification — Round 1

Claim: $A(h_1, x_1) \neq f(x_1)$.

Proof:

  • $h_1 = [\,]$ (empty history at round 1).
  • $f(x_1) = b = \lnot A([\,], x_1)$ by definition of $b$.
  • Therefore $A([\,], x_1) \neq \lnot A([\,], x_1) = f(x_1)$. $\checkmark$
Lemma (History agreement). For all $t \geq 1$, $$h_{t+1} \;=\; \mathrm{hist}(f, \mathbf{x}, t+1) \;=\; (x_1, b) \mathbin{::} \mathrm{hist}(g, (x_2,\ldots,x_T), t).$$

Why? The first pair is $(x_1, f(x_1)) = (x_1, b)$. For $i \geq 2$: $x_i \neq x_1$ (non-repeating), so $f(x_i) = g(x_i)$. Hence the tail of the history is $\mathrm{hist}(g, (x_2,\ldots,x_T), t)$.

11
Verification — Round $t+1$

Claim: $A(h_{t+1}, x_{t+1}) \neq f(x_{t+1})$ for each $t \geq 1$.

Proof:

  1. By the History Agreement Lemma: $h_{t+1} = (x_1, b) :: \mathrm{hist}(g, (x_2,\ldots,x_T), t).$
  2. So $A(h_{t+1}, x_{t+1}) = A\!\bigl((x_1,b) :: \mathrm{hist}(g,(x_2,\ldots,x_T),t),\; x_{t+1}\bigr) = A'(\mathrm{hist}(g,(x_2,\ldots,x_T),t),\; x_{t+1}).$
  3. Since $x_{t+1} \neq x_1$ (non-repeating): $f(x_{t+1}) = g(x_{t+1}).$
  4. By the inductive hypothesis on $g$: $A'(\mathrm{hist}(g,(x_2,\ldots,x_T),t),\; x_{t+1}) \neq g(x_{t+1}) = f(x_{t+1}).$ $\checkmark$
$f$ makes $A$ err at every round $t \in \{1,\ldots,T\}$. QED.

4. Lean 4 Formalization
13
Lean 4 — Definitions
-- Online learner: history → query → prediction
abbrev OnlineLearner (X : Type*) :=
  List (X × Bool) → X → Bool

-- History seen before round t against target f
def historyTo (f : X → Bool) (xs : List X) (t : Nat) :
    List (X × Bool) :=
  (xs.take t).map (fun x => (x, f x))

-- Mistake at round t
def MistakeAt (A : OnlineLearner X) (f : X → Bool)
    (xs : List X) (t : Nat) : Prop :=
  ∀ h : t < xs.length,
    A (historyTo f xs t) (xs.get ⟨t, h⟩) ≠ f (xs.get ⟨t, h⟩)

The history is the prefix of length $t$, mapped to labelled pairs. MistakeAt is universally quantified over the bound proof so the statement is well-typed for all $t$ simultaneously.

14
Lean 4 — Theorem & Proof Sketch
theorem exists_adversarial_target
    (A : OnlineLearner X) (xs : List X) (hxs : xs.Nodup) :
    ∃ f : X → Bool, ∀ t, MistakeAt A f xs t := by
  induction xs generalizing A with
  | nil =>   -- vacuous
      exact ⟨fun _ => false, fun t h => absurd h (by simp)⟩
  | cons x xs ih =>
      let b  := !A [] x                            -- adversarial label
      let A' := fun h y => A ((x, b) :: h) y       -- shifted learner
      obtain ⟨g, hg⟩ := ih A' (nodup_tail hxs)     -- IH on tail
      let f  := fun y => if y = x then b else g y -- combined target
      refine ⟨f, fun t => ?_⟩
      cases t with
      | zero  => dsimp [historyTo, f, b]; cases A [] x <;> simp
      | succ t => simpa [A', f, hget_ne'] using hg t ht'
#print axioms exists_adversarial_target outputs only propext, Classical.choice, Quot.sound — the standard Lean/Mathlib axioms. No sorry.

Discussion & Takeaways

What the theorem says

  • Every deterministic online learner can be completely fooled by an adaptive adversary.
  • The adversary constructs $f$ greedily: one coordinate at a time.
  • The query sequence can be arbitrary (any non-repeating order).

Why non-repeating?

  • Needed to ensure $x_1 \notin \{x_2,\ldots,x_T\}$ for the history lemma.
  • With repeats, $A$ already knows the label and cannot be fooled on a repeat.

Relation to PAC learning

  • In PAC learning, the target is fixed before the learner runs — adversarial adaptation is not allowed.
  • This theorem shows why the adversarial model is strictly harder.
Note. The proof is constructive: the adversary's strategy is a simple recursive algorithm with one evaluation of $A$ per round.

Summary
Theorem (Online Adversarial NFL, restated). $\;\forall A,\;\forall$ non-repeating $\mathbf{x}$, $\;\exists f : \mathcal{X}\to\{0,1\}$ such that $A$ errs at every round.

Proof method: Induction on $|\mathbf{x}|$.

  • Base: empty sequence — vacuous.
  • Step:
    1. Set $b = \lnot A([], x_1)$ (fool round 1).
    2. Build shifted learner $A'(h,y) = A((x_1,b)::h,\,y)$.
    3. Apply IH to $A'$ on $(x_2,\ldots,x_T)$ to get $g$.
    4. Set $f(y) = b$ if $y=x_1$, else $g(y)$.
There is no free lunch for online deterministic learners against adaptive adversaries.
