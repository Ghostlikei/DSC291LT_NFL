Motivation

Which is better — simulated annealing or random search?

Trick question.

Hill climbing, simulated annealing, evolutionary algorithms, and uniform random search are indistinguishable on average over all cost functions.

Any algorithm's gain on one class of problems is exactly offset by losses elsewhere.

NFL: The "skill" of a real-world optimiser is not intrinsic — it is an alignment between the algorithm's inductive bias and the (non-uniform) prior $P(f)$ over problems actually encountered.

Framework — Four Objects

Four Objects Do All the Work

1 — Sample
$d_m = \{(x_1,y_1),\ldots,(x_m,y_m)\}$ — time-ordered, distinct queries.
$d_m^x$ = query sequence, $\;d_m^y$ = cost-value sequence.
2 — Algorithm
$a : d \mapsto x \notin d^x$
— maps current sample to next unvisited query.
Covers SA, GA, hill climbing, tabu search.
3 — Performance
$P(d_m^y \mid f, m, a)$
— probability algorithm $a$ produces cost-value sequence $d_m^y$ on function $f$ after $m$ queries.
4 — Prior
$P(f)$ over $\mathcal{F} = \mathcal{Y}^{\mathcal{X}}$
— $|\mathcal{F}| = |\mathcal{Y}|^{|\mathcal{X}|}$ elements.
Uniform prior = complete ignorance about $f$.

Any scalar performance measure $\Phi(d_m^y)$ (best-so-far, mean, etc.) is a function of $P(d_m^y \mid f, m, a)$.

Part II
Main Theorem
5
Theorem 1 — Static NFL

Theorem 1 (Wolpert–Macready, 1997)

For any two algorithms $a_1, a_2$, any $m$, and any target cost-value sequence $d_m^y$: $$\sum_{f \in \mathcal{F}} P(d_m^y \mid f,\, m,\, a_1) \;=\; \sum_{f \in \mathcal{F}} P(d_m^y \mid f,\, m,\, a_2).$$

What it says: The number of cost functions on which $a$ produces exactly $d_m^y$ is the same for every $a$.

Corollary. For any scalar performance measure $\Phi$: $$\sum_{f} \mathbb{E}_a[\Phi(d_m^y)] \;\text{ is equal for every }a.$$
Takeaway. Averaged over all cost functions, every non-revisiting algorithm is equivalent. Performance advantage requires — and reveals — prior knowledge about $f$.

Proof

Proof — Induction on $m$

Proof by Induction on $m$

Core insight. Any algorithm picks coordinates of $f$ in some order. Summing over all $f \in \mathcal{F}$ makes every ordering — and every algorithm — equivalent.

Base case ($m = 1$):

  • Algorithm $a$ makes first query $x_1 = a(\emptyset)$.
  • Event "$d_1^y = (y_1)$" requires $f(x_1) = y_1$ — fixes one coordinate of $f$.
  • Remaining $|\mathcal{X}|-1$ coordinates are free: exactly $|\mathcal{Y}|^{|\mathcal{X}|-1}$ functions in $\mathcal{F}$ qualify.
  • This count is independent of which $x_1$ the algorithm chose.
$$\sum_{f} P(d_1^y \mid f, 1, a) = |\mathcal{Y}|^{|\mathcal{X}|-1} \quad \forall\, a.$$
8
Proof — Inductive Step: Inside / Outside Split

Inductive Step: Inside / Outside Split

Decompose the probability:

$$P(d_{m+1}^y \mid f, m{+}1, a) = \underbrace{P(y_{m+1} \mid d_m^y, f, a)}_{\text{next obs.}} \cdot \underbrace{P(d_m^y \mid f, m, a)}_{\text{history}}$$
Inside $d_m^x$. Query $x_{m+1} = a(d_m^x, d_m^y)$ depends only on $f$'s values at points already queried.
$\Rightarrow$ "inside" sum = inductive hypothesis $= |\mathcal{Y}|^{|\mathcal{X}|-m}$, independent of $a$.
Outside $d_m^x$. New observation $y_{m+1} = f(x_{m+1})$ depends only on $f$'s value at a point outside $d_m^x$ (non-revisiting).
$\Rightarrow$ "outside" sum $= |\mathcal{Y}|^{|\mathcal{X}|-m-1}$, independent of $a$.
$$\sum_{f} P(d_{m+1}^y \mid f, m{+}1, a) \;=\; |\mathcal{Y}|^{|\mathcal{X}|-m-1} \cdot |\mathcal{Y}|^{|\mathcal{X}|-m} \quad \text{independent of }a. \quad\square$$

The Geometric Picture

Geometric Interpretation

Algorithms as Vectors

Define (in $|\mathcal{F}|$-dimensional space):

  • $\vec{v}_{a,m}(f) := P(d_m^y \mid f, m, a)$ — behaviour vector of $a$
  • $\vec{p}(f) := P(f)$ — prior vector

Performance of $a$ under prior $P$:

$$P(d_m^y \mid m, a) = \vec{v}_{a,m} \cdot \vec{p}$$
NFL. All $\vec{v}_{a,m}$ have the same projection onto $\vec{1}$ (the uniform-prior diagonal). Different algorithms point in different directions off the diagonal.

Good performance = alignment: $a$ beats $a'$ on prior $\vec{p}$ iff $\vec{v}_a$ points more toward $\vec{p}$ than $\vec{v}_{a'}$ does.

Extensions and Scope

When Does NFL Hold?

Stochastic algorithms. Replace deterministic $a$ with stochastic $\sigma$ specifying $P(x_{m+1} \mid d_m, \sigma)$. The inside/outside split still holds. Proof carries through identically.
Time-varying $f$ (Theorem 2). Cost function evolves by a bijection $T: \mathcal{F} \to \mathcal{F}$. Average over all bijections $T$ instead of all $f$. Each inner sum = $(|\mathcal{F}|-1)!$, independent of $a$.

NFL holds beyond uniform $P(f)$:

  • Factorisable: $P(f) = \prod_x P'(f(x))$ — i.i.d. cost values at each domain point.
  • Permutation-closed: $P$ is invariant under relabelling of rank-ordered cost values.
The mere existence of structure in $P(f)$ doesn't justify any algorithm — the structure must be known and exploited.

-- Algorithm: nextQuery encodes P(x_{m+1} | d_m, a)
structure SearchAlg (X Y : Type*) where
  nextQuery : List (X × Y) → PMF X

-- Non-revisiting: a : d ↦ x ∉ d^x
def NonRevisiting (A : SearchAlg X Y) :=
  ∀ h x, x ∈ h.map Prod.fst → A.nextQuery h x = 0

-- Σ_f P(d_m^y | f, m, a)  is independent of a:
theorem wolpert_macready

Summary and Q&A

What We Showed

  • Framework: four objects — sample $d_m$, algorithm $a$, performance $P(d_m^y \mid f,m,a)$, prior $P(f)$.
  • Theorem 1: $\sum_f P(d_m^y \mid f,m,a_1) = \sum_f P(d_m^y \mid f,m,a_2)$ for all $a_1, a_2$.
  • Proof: induction on $m$; inside/outside split of $\sum_f$ makes every coordinate ordering equivalent.
  • Geometry: all behaviour vectors $\vec{v}_a$ have equal projection onto $\vec{1}$; performance = alignment with $\vec{p}$.
  • Scope: holds for stochastic algorithms, time-varying $f$, and many non-uniform priors.
Anticipated objection. "SA beats random search on real problems." — Yes, because real problems are not uniformly distributed. SA's gain on locally-structured problems is exactly paid for by losses on deceptive ones. NFL makes this trade-off explicit.
